Simple Gym

Log sets and track rest without breaking your workout flow.

Simple Gym turns your Suunto watch into a focused gym companion. The app starts in WAITING; hold the top button to begin at exercise 1, set 1. During a set there is no rest timer: an open-ended set timer counts up. Press the lower button to end the set and start rest. Press it again when you are ready for the next set; the set timer restarts and SETS advances. No menus, no exercise names, no rep counting — just the numbers that matter during a session.

When rest reaches zero the watch beeps or vibrates once, then switches to REST OVER and counts up until your next lower-button press starts the next set.

What you see:

- Current exercise number and current set
- A large state and timer: WAITING, SET with a count-up timer, REST with a countdown, or REST OVER with overtime
- Total sets started and session duration

Controls:

- Hold the top button to start at EX 1 / SET 1, and later to move to the next exercise.
- During a set, press the lower button to end it and restart the rest timer.
- During rest, press the lower button to start the next set and clear the rest timer.
- On UI1 watches, the first lap starts EX 1 / SET 1; later laps alternate between ending a set and starting the next.
- The workout screen intentionally shows no button reminders.

After the workout, the Suunto app shows a compact summary: sets started and total exercises used. The workout log saves the same two totals: total sets and total exercises.

Set your rest length once in the Suunto app settings (0–600 seconds, default 30) and optionally turn the rest alert off. Rest timing follows the activity clock, so pausing the workout pauses the countdown too.

Simple Gym is designed for UI2 Suunto watches with a responsive layout for n, o, and q displays, plus a minimal fallback for UI1 watches. Exercise switching requires a UI2 watch with button event support.

No GPS, no heart rate, no account, no network connection. Just sets and rest.
